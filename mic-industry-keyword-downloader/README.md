# MIC 行业关键词批量下载

这是一个 Chrome Manifest V3 插件，用于批量下载[中国制造网数据罗盘的行业关键词报表](https://data.made-in-china.com/industry/keyword)。每个「行业 × 月份」组合保存一份站点原生 XLSX，其中包含“行业热词”和“行业趋势词”两张工作表；无需逐页翻阅 TOP100。

## 安装

1. 解压交付的 ZIP 文件。
2. 在 Chrome 打开 `chrome://extensions`，开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择解压后的 `mic-industry-keyword-downloader` 文件夹。

## 使用

1. 登录 MIC 数据罗盘，打开“关键词分析 → 行业关键词”。
2. 将页面的“选择区域”设为“全球”。
3. 点击插件图标，勾选要下载的月份与行业。行业列表来自当前账号已设置的行业目录，包括父类和子类。
4. 点击“开始下载”。弹窗关闭后任务会继续；再次打开可查看进度、暂停或继续。
5. 文件保存在 Chrome 默认下载目录下的 `MIC行业关键词/月份/`，文件名含行业名称、行业 ID 和月份。

一次最多选择 250 个组合。暂停后，正在进行的那一份会完成，其余任务等待继续。失败项显示在进度区，待任务结束后可重新选择并下载。

## 范围与数据

- 仅提供页面可选的月份和当前账号已设置的行业。
- 当前版本支持“全球”区域。
- 使用 MIC 原生导出接口，报表内容和权限以站点返回为准。
- 插件不收集账号密码，不向其他站点发送数据，也不在插件中存储报表内容。任务和勾选记录只保存在本机 Chrome 扩展存储中。
- 若 MIC 改动页面结构或导出接口，插件可能需要更新。

## 权限说明

- `tabs`、`scripting`：识别并读取当前打开的 MIC 行业关键词页面。
- `downloads`：将报表保存到本机下载目录。
- `storage`：保存勾选记录和任务进度。
- `alarms`：浏览器暂停后台进程后继续检查下载状态。
- `https://data.made-in-china.com/*`：读取已设置的行业目录，并从 MIC 下载报表。
