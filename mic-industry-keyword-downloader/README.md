# MIC 行业关键词批量下载

这是一个 Chrome Manifest V3 插件，用于批量下载[中国制造网数据罗盘的行业关键词报表](https://data.made-in-china.com/industry/keyword)。每个「行业 × 月份」组合保存一份站点原生 XLSX，其中包含“行业热词”和“行业趋势词”两张工作表；无需逐页翻阅 TOP100。需要 Chrome 116 或更高版本。

## 安装

1. 解压交付的 ZIP 文件。
2. 在 Chrome 打开 `chrome://extensions`，开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择解压后的 `mic-industry-keyword-downloader` 文件夹。

## 使用

1. 登录 MIC 数据罗盘，打开“关键词分析 → 行业关键词”。
2. 将页面的“选择区域”设为“全球”。
3. 点击插件图标，选择“设置保存路径”，在系统窗口中选择或新建一个文件夹，并允许写入。选择后保留设置页打开，切回 MIC 页面并重新打开插件。
4. 勾选要下载的月份与行业。行业列表来自当前账号已设置的行业目录，包括父类和子类。
5. 点击“开始下载”。弹窗关闭后任务会继续；再次打开可查看进度、暂停或继续。
6. 每次任务会在所选文件夹中新建 `MIC行业关键词_时间_编号` 子文件夹，报表按月份放在里面，文件名含行业名称、行业 ID 和月份。

一次最多选择 250 个组合。暂停后，正在进行的那一份会完成，其余任务等待继续。失败项显示在进度区，待任务结束后可重新选择并下载。

勾选或取消一个类别时，会同步勾选或取消其所有子项目，包括搜索时隐藏的子项目。部分选中时，类别复选框显示中间状态。“全选当前结果”仅选择搜索结果中显示的项目。

## 范围与数据

- 仅提供页面可选的月份和当前账号已设置的行业。
- 当前版本支持“全球”区域。
- 使用 MIC 原生导出接口，报表内容和权限以站点返回为准。
- 插件不收集账号密码，不向其他站点发送数据。任务、勾选记录和所选文件夹的访问凭据保存在本机浏览器中；报表保存在你选择的文件夹。
- 浏览器只提供所选文件夹的名称，插件无法显示完整路径。浏览器重启后可能需要通过“设置保存路径”重新授权；任务进行中或暂停时不能更改文件夹。
- Brave 默认可能关闭文件系统访问功能。如果设置页提示无法选择文件夹，请在地址栏打开 `brave://flags/#file-system-access-api`，将 File System Access API 设为 Enabled 并重启 Brave。这个开关对整个浏览器生效，网站访问所选文件仍需用户授权。
- 若 MIC 改动页面结构或导出接口，插件可能需要更新。

## 权限说明

- `tabs`、`scripting`：识别并读取当前打开的 MIC 行业关键词页面。
- `storage`：保存勾选记录和任务进度；浏览器的 IndexedDB 保存你选择的文件夹访问凭据。
- `alarms`：浏览器暂停后台进程后继续检查下载状态。
- `offscreen`：在弹窗关闭后读取报表并写入你授权的文件夹。
- `https://data.made-in-china.com/*`：读取已设置的行业目录，并从 MIC 下载报表。
