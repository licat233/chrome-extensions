Brave 文件夹访问设置

在地址栏打开 brave://flags/#file-system-access-api，将 File System Access API 设为 Enabled，然后重启 Brave。重启后返回本页面选择文件夹。

这是浏览器级设置，会让其他网站也能申请文件访问权限；网站仍需要你授权才能访问所选文件。

浏览器只向插件提供文件夹名称，不显示完整路径。浏览器重启后可能需要重新授权。下载进行中不能更改保存位置。
