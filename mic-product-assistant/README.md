# MIC Product Assistant

这是一个本地 Chrome 插件，用来提取 Made-in-China 产品编辑页表单上下文，并把 Hermes agent / AI 生成的产品资料文本自动填入 Made-in-China 产品上传/修改页面。

插件现在按页面板块填充，不再用全页面字段猜测。每个板块会先绑定自己的 DOM 区域，再只在这个区域里查找和填写输入框，避免 A 板块的信息误填到 B 板块。

## 安装

1. 打开 Chrome，进入 `chrome://extensions/`
2. 打开右上角“开发者模式”
3. 点击“加载已解压的扩展程序”
4. 选择这个文件夹：

   `/Users/licat/chrome_extensions/mic-product-assistant`

## 使用

1. 打开 Made-in-China 产品上传或修改页面
2. 点击浏览器右上角插件图标
3. 粘贴 Hermes skill 生成的产品资料
4. 点击“填充当前页面”

也可以先复制好整段资料，然后点“读取剪贴板并填充”。

## 一键提取产品信息

在 MIC 产品上传或编辑页面点击“一键提取并复制”，插件会读取当前页面可回填的表单字段，把结构化 JSON 放入插件文本框并复制到剪贴板。该 JSON 可直接交给 AI，内容包括：

- 字段所在板块、字段名、当前值、必填状态、控件类型和平台可选值
- `bulkFillFieldName` 兼容字段名，表示 AI 生成回填文本时应该使用的字段名
- `domLocator` 轻量 DOM 定位信息，便于和页面字段绑定规则对照
- MIC 默认标准属性与固定属性
- 用户通过“添加自定义属性”手动新增的属性
- 当前定价模式及该模式下正在启用的价格字段

`select`、`radio`、`checkbox` 字段会包含 `options: [...]`，让 AI 知道优化值必须从 MIC 平台选项中选择。`产品展示`、`运费信息` 和 `产品详情` 不参与一键提取；这些板块不能通过批量文本稳定回填，提取出来只会污染 AI 上下文。

提取结果里的 `fieldName` 表示当前页面的具体表单槽位，`bulkFillFieldName` 表示生成回填文本时应使用的字段名。例如多个规格值槽位会提取为 `规格1值1`、`规格1值2`，但它们的 `bulkFillFieldName` 都是 `规格值`，AI 应生成 `规格值：A; B`。

如果 `规格管理` 模块存在但当前没有渲染任何规格输入框，提取结果会保留该 section，并标记 `exists: true, empty: true`；同时输出 `规格1名称` 和 `规格1值1` 两个空值骨架字段，分别映射到 `bulkFillFieldName: 规格名称` / `规格值`，提醒 AI 这个必填评分模块需要补充。

产品属性的来源由 DOM 结构判定：`.J-stand-prop` 是 MIC 标准属性，固定的运输包装/规格/商标/原产地是 MIC 固定属性，`.J-selfprop` 中的属性名和值是手动添加的自定义属性，不依赖字段名称猜测。

## 文本格式

每个板块使用 `# 板块名称`，每个字段使用 `字段名：内容`。

板块顺序必须按页面视觉顺序输出：

1. `# 基本信息`
2. `# 产品亮点`
3. `# 产品属性`
4. `# 规格管理`
5. `# FOB价格设置`
6. `# 计量单位`
7. `# 包裹尺寸`
8. `# 发货效率信息`
9. `# 样品单交易设置`
10. `# 其他信息设置`
11. `# FAQ`

## 关键规则

- `产品属性` 里的必填标准属性包括：`认证`、`功率`、`发光颜色`、`电压`、`防护等级`、`运输包装`、`规格`、`商标`、`原产地`。
- `IP Rating` 不要作为自定义属性输出；它已经对应标准属性 `防护等级`，重复填写会被页面提示属性名已存在。
- `电压` 是标准属性，通常只能选择一个页面选项，例如 `12V`；多个电压版本请写到 `规格管理`，例如 `规格名称：Voltage`、`规格值：12V; 24V`。
- `中心词` 页面只能选择 1 个；插件会先填写产品名称但不阻塞主流程，再用后台 `MutationObserver` 优先监听中心词模块容器；只有候选节点或候选内容更新并短暂稳定后，才按 AI 输出顺序选择第一个匹配项，避免选中旧候选后又被页面重置。
- `FOB价格设置` 会根据字段自动选择价格模式：一口价、阶梯价、区间价。
- `规格管理` 与 FOB 定价模式相互独立：没有规格表单时会自动点击“添加规格”；多组规格会继续新增表单；同一规格有多个值时会逐次点击“添加”新增规格值。
- `样品单交易设置` 如果输出 `提供样品：是`，AI 应同时输出真实的 `单次最多拿样数量`；插件只按文本填写，不自动猜默认数量，但会强制显示/启用样品单价、单位、最多拿样数量和描述字段。
- `关键词` 支持最多 20 个槽位；插件会按需点击“添加关键词”补齐。
- `产品展示`、`运费信息` 和 `产品详情` 不需要输出字段；图片/视频、运费模板和详情编辑器不会由批量文本稳定处理。
